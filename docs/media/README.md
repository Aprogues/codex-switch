# Documentation screenshot

`demo.png` is the only documentation image: one 800×560 static PNG, rendered from the current Windows UI by `python scripts/render-demo.py`.

The visible **DEMO** label and reserved `example.invalid` addresses identify fictional data. The recipe deliberately combines 1%, 0% and 100% quota, exhausted reset rights, remaining credits, an expired subscription, 42 running / 128 queued / 9 goal counts, 97–100% resource load and an almost-full drive.

The 12-minute forecast is calculated by the actual usage predictor from synthetic history. No real accounts, authentication, live tasks or native Codex process are used. Resource warnings are simulated, not generated by stressing the machine.

`demo.json` records the inputs/source/date. The image has no private identities or image text/EXIF metadata. Re-render it when the UI changes. Do not treat this image as real account-switch, performance or Mac acceptance evidence.

Older GIFs, size variants and duplicate posters were removed from the current tree.
