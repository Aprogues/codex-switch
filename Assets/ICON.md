# Codex Switch icon

The maintainer supplied the cloud/terminal silhouette and requested the center be changed to `>_<`. The built-in ImageGen edit produced `mark.png`, a transparent monochrome mark. Windows ICO and Mac PNG/ICNS assets are resized from that mark; UI chrome and template menu icons use its alpha mask with the current foreground color.

Edit prompt: "Preserve the thick rounded irregular cloud perimeter. Replace only the inner terminal symbols with a playful literal >_< face: two inward-pointing chevron squint eyes and a short underscore mouth centered below. Flat near-black strokes, actual transparent background, no tile, shadow, gradient or extra lettering."
